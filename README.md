# 2026Competition

The OffSeason-195 branch retrofits the 2026 robot for PhotonVision and improved drive/aim control.

**Continuing on another computer?** Read the [portable handoff](docs/offseason-195/HANDOFF.md) and
paste the [continuation prompt](docs/offseason-195/CONTINUE_PROMPT.md) into the new coding chat.
The [task list](docs/offseason-195/TASKS.md) and [gotchas](docs/offseason-195/GOTCHAS.md) preserve open work.

Start with the [off-season installation, calibration and test guide](docs/offseason-195/README.md).
Real camera offsets are intentionally uncalibrated until measured; desktop test results are not
a claim of competition readiness.
